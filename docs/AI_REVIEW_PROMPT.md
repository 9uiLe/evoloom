# Screen review prompt

Review this iOS screen for a user who needs to complete the stated task.
Describe the information hierarchy, which items belong together, the primary
action, and whether NavigationStack, List, Form, search, sheet or system alert
would serve the flow. Check Dynamic Type, VoiceOver order, labels, error
recovery, disabled/loading behavior, narrow width, Japanese/English length,
dark mode and Increased Contrast. Use `DESIGN.md` and public component APIs.
For each finding, distinguish an observed fact, a testable hypothesis, and a
personal preference. Cite the screenshot or code path for observed facts.
Propose the smallest change that improves the user's task and a way to verify
it. Do not invent visual tokens per screen.
